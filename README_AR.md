# python-ad-network

> 🇬🇧 [English version](README.md)

**نواة شبكة إعلانات** صغيرة تستضيفها بنفسك لألعاب وتطبيقات بايثون. تعمل مع **pygame وturtle وtkinter**، ومع **أي مكتبة أخرى تفتح نافذة** عبر نافذة إعلان مستقلة.

> ⚠️ **الحالة: Alpha (تجريبي).** هذا **أساس** تبني عليه وليس منتجًا مكتملًا. يعمل ومُختبَر على لينكس، لكن توقّع نواقص وأخطاء. راجع [النواقص](#النواقص-في-مرحلة-ألفا) و[خارطة الطريق](ROADMAP.md). **لا تستخدمه لفوترة معلنين الآن**، فأرقام النقرات قابلة للتزوير.

## لماذا هذا المشروع؟
منتجات إعلانات Google لا تدعم ألعاب بايثون على سطح المكتب (AdMob لتطبيقات الموبايل، وAdSense للمواقع). فإذا كنت تصنع ألعابًا صغيرة وتريد الترويج لألعابك الأخرى أو عرض إعلان راعٍ أو تعلّم كيف يعمل سيرفر إعلانات، فأنت بحاجة إلى شيء بسيط تتحكم فيه. هذا هو نقطة البداية.

## ماذا يوفّر؟
- **السيرفر** (Flask + SQLite): عدة إعلانات بالتناوب حسب الوزن، مرات الظهور والنقرات ونسبة النقر، إحصائيات يومية، لوحة تحكم عربية/إنجليزية مع رفع الصور بالسحب والإفلات.
- **العميل:** لا يجمّد اللعبة (خيط خلفي)، تجديد تلقائي، تخزين للعمل بدون إنترنت، فتح آمن للروابط (http/https فقط)، تتبع الظهور والنقر.
- **المحوّلات:** pygame (`GameAd`) وtkinter (`TkAd`) وturtle (`TurtleAd`)، و`launch_ad_window()` لأي مكتبة أخرى.
- **الاختبارات:** 11 اختبارًا آليًا (أمان السيرفر والتتبع وpygame وtkinter وturtle).

## بداية سريعة

**1. السيرفر:** استضفه مجانًا على PythonAnywhere. الخطوات الكاملة في [ad-server/README_AR.md](ad-server/README_AR.md).
يجب ضبط كلمة مرور الإدارة أولًا (وإلا تبقى اللوحة مقفلة):
```python
import os
os.environ["AD_ADMIN_PASSWORD"] = "كلمة-مرور-قوية"   # 8 أحرف أو أكثر
```

**2. العميل:** انسخ الملفات المطلوبة من مجلد `client/` بجانب لعبتك (`adcore.py` مطلوب دائمًا):
```python
# pygame
from ad_client import GameAd
ad = GameAd("https://yourname.pythonanywhere.com", x=250, y=500, width=300, height=80)
ad.start()                  # قبل حلقة اللعبة
ad.handle_event(event)      # داخل الحلقة لكل حدث
ad.draw(screen)

# turtle
from ad_tk import TurtleAd
TurtleAd(turtle.Screen(), "https://yourname.pythonanywhere.com", x=0, y=-250)

# tkinter
from ad_tk import TkAd
TkAd(root, "https://yourname.pythonanywhere.com").pack()

# أي مكتبة أخرى: يظهر الإعلان في نافذة صغيرة مستقلة
from ad_window import launch_ad_window
launch_ad_window("https://yourname.pythonanywhere.com")
```
المزيد في [client/README.md](client/README.md) وملفات `client/example_*.py`.

## هيكل المشروع
```
ad-server/flask_app.py     السيرفر كاملًا (API + لوحة التحكم + قاعدة البيانات)
client/adcore.py           النواة المستقلة عن الواجهات: تحميل، تجديد، تخزين، تتبع، نقر آمن
client/ad_client.py        محوّل pygame         ┐
client/ad_tk.py            tkinter و turtle     ├ محوّلات رفيعة فوق adcore
client/ad_window.py        نافذة مستقلة         ┘ لأي مكتبة أخرى
tests/                     الاختبارات الآلية
```
دعم مكتبة جديدة = كتابة محوّل صغير فوق `AdCore` (انظر `client/example_any_library.py`). وهذه أسهل طريقة للمساهمة.

## النواقص في مرحلة ألفا
اعرفها قبل الاستخدام:
- 🔓 **النقرات والظهور قابلة للتزوير:** أي شخص يعرف الرابط يستطيع إرسال أحداث وهمية. حد عدد الطلبات لكل IP يبطّئ الإغراق فقط.
- لا حسابات معلنين ولا فوترة ولا مراجعة محتوى ولا استهداف. تضيف الإعلانات يدويًا من لوحة التحكم.
- اختيار عشوائي حسب الوزن فقط (بلا مزاد ولا حد لتكرار الظهور ولا جدولة).
- مُختبَر على **لينكس** مع Python 3.12 فقط. ويندوز وmacOS وبيئة PythonAnywhere الفعلية لم تُختبر.
- SQLite على استضافة مجانية تكفي للمشاريع الصغيرة وليس للزيارات الكثيرة.
- لا أدوات GDPR أو موافقات، والتزاماتك القانونية مسؤوليتك.
